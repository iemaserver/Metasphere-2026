# MetaSphere 2026

Official web repository for **MetaSphere 2026: The International Conference on Cloud Computing, Virtualization, and the Metaverse**.

This repository hosts the official frontend codebase, designed for high performance, device responsiveness, and search engine optimization (SEO) in compliance with Google Search Central guidelines.

---

## 🌐 About the Conference

MetaSphere 2026 serves as a premier global forum bridging academic researchers, industry experts, and engineers. The conference facilitates the exchange of ideas, methodologies, and advancements in the domains of Cloud infrastructures, virtualization paradigms, and the evolving Metaverse ecosystem.

### Key Details:
- **Organizer:** Department of Computer Application (BCA) & IEM Centre of Excellence
- **Host Institution:** Institute of Engineering & Management (IEM), Kolkata, India
- **Venue:** IEM Ashram Building, Sector V, Bidhannagar, Kolkata - 700091 (Hybrid Format)
- **Official Domain:** [https://metasphere-2026.web.app](https://metasphere-2026.web.app)

---

## 📚 Technical Focus & Tracks

The conference program covers key technical areas including:
1. **Cloud & Virtualization Infrastructure:** Distributed systems, containerization, edge/fog computing, serverless architectures, and resource virtualization.
2. **Metaverse Technologies & Immersive Web:** AR/VR systems, 3D graphics pipeline, spatial computing, and digital twin simulation.
3. **AI & Cognitive Integration:** Machine learning at scale, intelligent agents, and cognitive cloud services.
4. **Security, Privacy & Blockchain:** Trust in distributed ledger technologies, privacy-preserving virtualization, and secure decentralized systems.

---

## 🛠️ Project Stack

The web interface is engineered for optimal performance and user experience, using a modern static site architecture:
- **Core:** Semantic HTML5 & Vanilla JavaScript
- **Styling:** Tailwind CSS (configured via CLI compiler)
- **Libraries:** AOS (Animate on Scroll) for UI transitions, Lucide Icons
- **Optimization:** Asynchronous video lazy loading, image layout constraint styling, and mobile responsiveness
- **Crawlability:** Standard Event & Organization Schema (JSON-LD), XML Sitemaps, and robots.txt
